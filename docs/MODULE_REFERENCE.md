Specialized modules: nil.boosting (explicit native CPU integrations),
nil.forecasting (direct lag/horizon and rolling-origin tests), nil.ranking
(query-safe fitting/metrics), nil.recommendation (bounded sparse retrieval),
nil.survival (right-censored Cox/KM), and nil.datasets (typed schemas and atomic
local ingestion). Inspection, selection and uncertainty expose the additional
bounded Shapley, distributed random-search and calibrated regression contracts.
Each has offline help; see CLASSICAL_SPECIALIZED.md for their exact scope.


## Explicit CPU completion modules

- `nil.native`: dependency-free small dense float64 CPU Tensor/autodiff, Linear
  and small Sequential models, SGD and plain JSON persistence.
- `nil.distributed`: explicit single-host fp32 supervised DDP; two-rank CPU
  acceptance, epoch checkpoints and rank-zero observers.
- `nil.rl`: optional neural offline BC/fitted-Q, structured rollout collection,
  recurrent/masked backend policies and supported CPU DQN simulator snapshots.
- `nil.optimization.activation_checkpoint`: Sequential activation recomputation.
- `nil.serving.create_isolated_server`: bounded authenticated loopback service,
  restartable trusted CPU worker, hard deadline and metrics.

Each has offline help. Scope, measured tests and unaccepted hardware/deployment
combinations: [CPU_COMPLETION.md](CPU_COMPLETION.md).

## Framework contracts and images

- `nil.coverage`: passive, versioned workflow inventory and metadata-only availability; `nil help coverage`.
- `nil.contracts`: structural dataset/predictor/result protocols and result_info metadata; `nil help contracts`.
- `nil.vision`: lazy bounded local image classification and saved preprocessing/labels; `nil help vision`.
- `nil.model("nelo_vision_mini", ...)`: compact trainable CNN baseline; `nil help nelo_vision_mini`.

See [SDK contracts](SDK_CONTRACTS.md), [workflow inventory](WORKFLOWS.md) and [image acceptance](VISION.md).

## Compact-model research readiness

Use the existing `nil.Trainer` custom-step interface and native Torch modules for
local shared-block experiments. The runnable `compact_research.py` example and
[readiness audit](RESEARCH_READINESS.md) document supported local behavior, the
current tied-parameter distributed restriction, measurement gaps and experimental
limits. There is no new mandatory research backend or import-time worker.

## Seven AI workflow areas

| Module | Implemented v1 |
|---|---|
| nil.rag | Cited BM25 retrieval, extractive/explicit-generator answers, updates and snapshots |
| nil.planning | Existing Tool plans, owned deadlines, cancellation, recovery and shortest paths |
| nil.probabilistic | Beta-Bernoulli, Bayesian linear prediction and cross-fitted causal ATE |
| nil.learning | Entropy queries, self-training, contrastive loss, prototypes and reservoir replay |
| nil.audio | Bounded PCM WAV, explicit resampling/segments and spectral classification features |
| nil.multimodal | Timed GIF/TIFF, opt-in FFmpeg video, audio alignment and fixed-schema fusion |
| nil.graphs | Sparse normalized propagation, disjoint batches, GCN node/graph classification |

Each module has bundled help.md. See [complete v1 contracts and limitations](SEVEN_WORKFLOWS.md).

Advanced seven-area additions and still-open requirements: [advanced workflow phase](ADVANCED_WORKFLOWS.md). New CPU checks are separate from the earlier v1 hosted matrix.
